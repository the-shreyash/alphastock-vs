# Support Policy

Thank you for using StockAssist AI. This document outlines how to ask questions, report bugs, suggest features, and find documentation support.

---

## How to Ask Questions

If you have general questions about setting up, configuring, or using StockAssist AI, please use our public discussion channels:

- **GitHub Discussions:** Use the **Q&A** category on GitHub to ask setup and usage questions.
- **Developer Forum:** Check out community boards for sharing custom broker adapters or AI routing scripts.
- **Documentation:** Search the `.claude/` directory and `docs/` directories first; most design and operational questions are answered in our technical documentation.

---

## How to Report Bugs

If you identify a bug in the application, please file a bug report via GitHub Issues. 

### Guidelines for Bug Reports
Before submitting a bug, check existing open issues to ensure it has not already been reported. When filing a new issue, please use our bug template and include:
1. **Title:** Clear, concise description (e.g., `fix(broker): Upstox auth token refresh failure`).
2. **Steps to Reproduce:** Exact sequence of steps to replicate the problem.
3. **Environment Details:** 
   - OS (macOS, Windows, Linux)
   - Python & Node.js version
   - DB and Redis status (local vs cloud instance)
4. **Expected vs. Actual Behavior:** What should have happened vs. what actually happened.
5. **Logs & Stack Traces:** Console logs, FastAPI backend logs, or network payloads.

---

## Feature Requests

We welcome ideas and feature suggestions! To suggest a feature:
1. Open a new issue and select **Feature Request**.
2. Explain the **use case** (e.g., "Why is this feature useful? How does it help retail investors?").
3. Describe the proposed solution or design.
4. All approved feature requests will be added to the backlog and prioritized against our [ROADMAP.md](file:///Users/shreyash12/Files/alpha_stock/alpha-stock-main/ROADMAP.md) phases.

---

## Documentation Support

If you find a typo, broken link, or outdated information in the documentation:
- Feel free to submit a pull request directly with the correction (following our [CONTRIBUTING.md](file:///Users/shreyash12/Files/alpha_stock/alpha-stock-main/CONTRIBUTING.md) commit guidelines).
- Alternatively, open an issue tagged `documentation` to request update revisions.
